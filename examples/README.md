# UserSim Examples

This directory contains example code demonstrating how to use UserSim.

## basic_conversation.py

A simple example showing the Step 1 conversation loop functionality:
- Connecting to a target agent via A2A protocol
- Sending messages in sequence
- Tracking conversation history
- Handling max turn limits

To run:
```bash
python basic_conversation.py
```

Note: This requires a real A2A-compatible agent endpoint. The example uses a placeholder URL.
